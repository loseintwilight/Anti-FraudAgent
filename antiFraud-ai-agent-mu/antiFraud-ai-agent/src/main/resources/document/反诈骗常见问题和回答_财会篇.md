# 第五篇：财会人员诈骗常见问题与案例

#### 问题1：财会人员收到领导微信、QQ消息，要求紧急私下转账、划拨资金，属于什么风险等级？

**解答**：风险等级为**高风险**，诈骗类型为冒充领导转账诈骗。

**典型案例**：企业会计刘某，被骗子盗取领导社交账号，冒充老板要求紧急向合作方账户转账20万元，未走线下核实、审批流程，转账后发现被骗，资金难以追回。

**诈骗话术模版**：“有笔紧急合作款，立马转到这个账户，事情机密，不用走线下审批，转完把凭证发我！”

**预警规则**：凡是线上要求紧急转账、规避正常审批流程的，一律电话、视频、面对面核实领导本人；严格执行企业资金转账审批制度，绝不私下转账。

**法律法规**：冒充他人实施诈骗，触犯《刑法》第二百六十六条诈骗罪，数额巨大的从严惩处；财会人员未履职导致资金损失，需承担相应责任。

#### 问题2：财会人员接到自称税务、财政工作人员电话，要求补缴税款、缴纳罚款，属于什么风险等级？

**解答**：风险等级为**中风险**，诈骗类型为冒充税务人员诈骗。

**典型案例**：小微企业出纳张某，接到自称税务局专员电话，称企业税务异常需补缴税款，要求私下转账至指定账户，切勿线下办理，张某转账8000余元后发现被骗。

**诈骗话术模版**：“企业税务申报异常，限当日内补缴税款，私下转账快速处理，逾期吊销税务资质、罚款翻倍！”

**预警规则**：税务相关业务均通过官方电子税务局、线下办税大厅办理，税务部门不会通过电话、微信要求私下转账；涉税信息务必通过官方渠道核实。

**法律法规**：冒充国家机关工作人员诈骗，属于诈骗罪从重处罚情节，触犯《刑法》第二百六十六条、第二百七十九条。

#### 问题3：财会人员收到合作客户消息，称变更对公收款账户，要求转账至新账户，属于什么风险等级？

**解答**：风险等级为**高风险**，诈骗类型为虚假客户账户变更诈骗。

**典型案例**：公司财务李某，收到冒充合作客户的消息，称原有对公账户停用，要求将货款转至新个人账户，李某未核实直接转账，被骗15万元。

**诈骗话术模版**：“公司账户升级，临时更换收款账户，麻烦把货款转到这个账户，后续补正规手续，不影响合作！”

**预警规则**：客户账户变更必须电话核实对方负责人，索要加盖公章的账户变更说明，严禁直接转账至陌生个人账户；对公转账严格核对账户信息。

**法律法规**：虚构事实骗取企业货款，触犯《刑法》诈骗罪，涉案金额巨大的依法追究刑事责任。

#### 问题4：财会人员被诱导参与税务刷单、票据冲量，承诺高额佣金，属于什么风险等级？

**解答**：风险等级为**中风险**，诈骗类型为财税刷单诈骗。

**典型案例**：兼职会计王某，轻信票据冲量刷单赚钱，按要求操作对公账户转账、虚假开票，先小额获利，后续投入5万元本金后，骗子失联，且自身涉嫌虚开发票违规。

**诈骗话术模版**：“财税内部刷单，安全合规，只用走个流水，一单佣金几百块，零风险、快速结算！”

**预警规则**：税务刷单、虚假票据均属于违法违规行为，坚决不参与；严禁利用对公账户、个人资质帮他人走账、刷单。

**法律法规**：涉案人员触犯诈骗罪、虚开发票罪、帮信罪，依法追究刑事责任；财会人员参与需承担连带法律责任。

#### 问题5：财会人员收到虚假增值税发票、报销票据，要求快速报销打款，属于什么风险等级？

**解答**：风险等级为**低风险**，诈骗类型为虚假票据报销诈骗。

**典型案例**：公司出纳陈某，收到员工提交的虚假差旅、办公发票，票面信息模糊、来源不明，未严格审核便完成报销，给公司造成数千元资金损失。

**诈骗话术模版**：“票据着急报销，领导已签字，麻烦尽快打款，不用仔细核验！”

**预警规则**：严格执行票据审核制度，通过税务平台核验发票真伪，核对票据信息、业务真实性，无正规手续、来源不明票据一律不予报销。

**法律法规**：使用虚假发票报销骗取资金，触犯诈骗罪、虚开发票相关法规；财会人员审核失职需承担企业追责。

#### 问题6：财会人员接到通知，称对公账户异常、被冻结，要求交钱解冻，属于什么风险等级？

**解答**：风险等级为**中风险**，诈骗类型为对公账户解冻诈骗。

**典型案例**：小企业财务赵某，接到陌生电话称企业对公账户涉嫌违规被冻结，需缴纳解冻金、保证金才能解封，转账1万元后，发现账户正常，骗子彻底失联。

**诈骗话术模版**：“对公账户涉案冻结，立马缴纳解冻费，线上快速办理，不去线下银行，否则账户永久封禁！”

**预警规则**：对公账户冻结、解封均需前往开户银行办理，无线上交钱解冻流程，绝不相信陌生电话、线上解冻话术。

**法律法规**：虚构账户异常事实骗取资金，触犯《刑法》诈骗罪，依法追责。

#### 问题7：财会人员被诱导代办高额退税、税收减免，要求缴纳代办费，属于什么风险等级？

**解答**：风险等级为**中风险**，诈骗类型为虚假财税代办诈骗。

**典型案例**：个体工商户财务林某，被骗子承诺可代办大额退税、税收减免，先后缴纳代办费、资料费2万余元，最终退税事项纯属虚构，费用无法追回。

**诈骗话术模版**：“内部渠道代办退税、减税，成功率百分百，先交代办费，退税款立马到账！”

**预警规则**：退税、减税均需通过官方税务渠道申请，无内部代办渠道，不相信高额退税、零门槛减税承诺。

**法律法规**：虚构财税代办业务骗取财物，触犯《刑法》诈骗罪，依法处罚。

#### 问题8：财会人员被拉入虚假财税交流群，被诱导投资财税理财、垫资项目，属于什么风险等级？

**解答**：风险等级为**高风险**，诈骗类型为财税领域投资诈骗。

**典型案例**：资深会计冯某，加入财税交流群后，被群内托诱导投资所谓税务理财项目，承诺年化40%收益，先后投入8万元，后续平台关闭，骗子失联。

**诈骗话术模版**：“财税专属理财，规避资金风险，保本保收益，业内人士都在投，资金安全有保障！”

**预警规则**：不加入陌生财税交流群，不相信群内投资、理财项目，高额保本收益均为骗局；涉及资金投资多方核实资质。

**法律法规**：涉案人员触犯集资诈骗罪、诈骗罪，数额巨大的依法判处有期徒刑，并处罚金。

#### 问题9：财会人员个人财务软件、网银账号被冒充客服索要验证码、账号密码，属于什么风险等级？

**解答**：风险等级为**高风险**，诈骗类型为冒充财税软件客服诈骗。

**典型案例**：财务人员周某，接到自称财务软件客服电话，称系统升级需提供账号、验证码，提供后企业网银账户被盗刷12万元。

**诈骗话术模版**：“财务系统升级，需要验证码同步信息，全程安全操作，不影响账户资金！”

**预警规则**：正规财税软件、网银客服绝不索要账号密码、验证码；妥善保管财务账户密钥、密码、U盾，不向任何人泄露。

**法律法规**：非法获取财务账户信息、盗刷资金，触犯盗窃罪、诈骗罪，依法从严惩处。

#### 问题10：财会人员被要求帮忙过账、代收代付陌生资金，赚取佣金，属于什么风险等级？

**解答**：风险等级为**高风险**，诈骗类型为财税帮信洗钱诈骗。

**典型案例**：兼职会计徐某，帮陌生客户代收代付资金赚取佣金，看似正常转账，实则协助洗钱，涉案流水50余万元，被认定为帮助信息网络犯罪活动罪。

**诈骗话术模版**：“只用对公账户过个账，走个正常流程，一笔佣金上千，合法合规，没有任何风险！”

**预警规则**：严禁利用企业对公账户、个人账户帮陌生第三方代收代付资金、过账，此类行为极易涉嫌洗钱、帮信罪，坚决拒绝。

**法律法规**：《刑法》第二百八十七条之二，帮助信息网络犯罪活动罪，明知他人实施犯罪仍提供资金结算帮助的，依法追究刑事责任。

#### 问题11：财会人员收到虚假银行回单、对账函，要求配合转账平账，属于什么风险等级？

**解答**：风险等级为**高风险**，诈骗类型为虚假银行单证平账诈骗。

**典型案例**：企业出纳郑某，收到骗子发送的虚假银行回单、对账函，谎称企业有未平账目，需紧急转账冲账，郑某未前往银行核实便转账18万元，事后发现单证均为伪造，资金被骗无法追回。

**诈骗话术模版**：“银行对账出现差异，这是回单凭证，赶紧转账平账，逾期影响企业征信，流程紧急不用逐级审批！”

**预警规则**：银行对账、平账业务必须通过开户行柜面、官方网银渠道核实，绝不相信虚假纸质、电子单证；涉及资金平账严格走企业内部审批流程。

**法律法规**：伪造银行单证、虚构平账事实骗取资金，触犯《刑法》诈骗罪、伪造金融票证罪，依法从严从重惩处。

#### 问题12：财会人员被诱导虚假申报个税、企业税，赚取违规佣金，属于什么风险等级？

**解答**：风险等级为**中风险**，诈骗类型为虚假税务申报诈骗。

**典型案例**：代账会计韩某，被骗子诱导为多家空壳公司虚假申报税务、虚报成本，承诺单笔佣金丰厚，后续被税务部门稽查，不仅面临罚款，还因协助虚假申报承担法律责任。

**诈骗话术模版**：“帮忙做税务零申报、虚报成本，流程简单不查账，一单佣金丰厚，全程帮你规避风险！”

**预警规则**：严格按照真实业务、合法票据办理税务申报，绝不参与虚假报税、虚报利润、虚列成本等违规操作，坚守财税从业底线。

**法律法规**：虚假税务申报触犯《税收征收管理法》，情节严重的触犯《刑法》逃税罪、虚开发票罪，财会人员需承担连带法律责任。
